# 本地网页工作台

```bash
cd BridgeDealer  # 进入已克隆并安装好的仓库
./dealer serve
```

浏览器打开 <http://127.0.0.1:8789>。若端口被占用，可使用 `./dealer serve --port 8790`。
服务仅监听本机，页面、字体和脚本不依赖外部 CDN。静态 HTML/CSS/JavaScript 随 Python 包分发。
先按根目录 README 安装 Python 依赖并运行 `uv run python scripts/build_dds.py` 编译附带的 DDS 3.1.0；位置与命令行后端相同。

## 通过 Cloudflare Tunnel 访问

```bash
.venv/bin/python -m bridge_dealer serve --port 12707 --public-origin https://bridge.kanami.top
```

服务仍仅绑定 `127.0.0.1`。将 Tunnel 的公网主机名设为 `bridge.kanami.top`；cloudflared 与服务处于同一网络命名空间时，
HTTP 回源设为 `http://127.0.0.1:12707`，Windows Docker connector 使用 `http://host.docker.internal:12707`。
保留公网 `Host`（如需显式覆盖，填写 `bridge.kanami.top`）；Windows 环境详见[部署说明](windows-deployment.md)。
`--public-origin` 只接受一个 HTTPS 来源，可带根目录尾斜杠，不允许用户名、密码、资源路径、查询或片段。
默认仍仅允许本机 `Host` 和对应的 HTTP `Origin`；启用后额外允许精确的公网 `Host` 和 HTTPS `Origin`。
无 `Origin` 的请求仍需通过 `Host` 检查；转发头和 Cloudflare 头不会增加访问权限。

**同源白名单不是用户认证。** 任务列表、任务结果、取消操作和磁盘模板均为服务内全局共享，
公开访问者可创建、读取、修改或删除相关状态。建议在 Cloudflare Access 为整个域名添加指定用户的访问规则；
需要独立状态时使用独立的服务实例和模板文件。HTTP 任务响应不会公开本地 DDS 动态库路径。

## 使用

页面固定在当前视口，不提供页面滚动。点击牌桌上的四家，在牌桌内展开紧凑条件菜单；
牌桌左上角的“牌局工具”默认折叠，展开后可载入示例、复制条件、导入、导出和重置；选择命令、点击外部或按 Esc 收起。
北家优先向下展开，南家优先向上，东西两家根据空间向内或上下展开，菜单始终限制在牌桌内。
点击中心盘就地展开定约菜单。条件和定约每次只展开一个菜单；
中心框只显示一个主定约，默认北家 3NT；外圈短高亮指向该定约的庄家。
选定目标后按 NT、♠、♥、♦、♣ 的顺序显示第一个定约，获得有效结果后显示成功率最高者；
同成功率时也按此顺序选择。修改条件或目标后，中心框先预览新选择，待新结果更新。
定约与牌张使用古典衬线字体 Baskerville（系统不提供时回退到 Palatino Linotype、Times New Roman），
数字采用等高、等宽样式，避免旧式数字的上下错落。
再次点击同一入口、点击空白、点击关闭按钮或按 Esc 收起，Esc 会将焦点返回入口。
牌桌右下角开始结算；右上角常驻解析结果缩略框，缩略框与详情统一使用深绿色底色、浅色文字。与牌桌上边和右边保持固定间距，只显示当前最高胜率的一个定约、庄家和成约概率，
以及后台是否在计算、累计已解析副数。没有有效结果时显示待计算，不预选最高胜率定约。
点击标题或概率区域展开详情，再点标题或按 Esc 收起。缩略框不遮挡四家卡片；
详情允许覆盖牌桌。牌桌始终保持北上南下、东右西左，四家卡片统一固定宽高，
修改条件、展开或收起详情、计算进度更新均不改变卡片尺寸或位置。屏幕尺寸变化时整体适配。
详情顶部提供“快速估计 / 全枚举真值”和可折叠的“计算参数”；下方可查看区间、样本、耗时、停止原因及下载 JSON，内容较多时内部滚动。
展开结果不关闭条件菜单，也不阻止编辑四家、切换定约或取消计算；定约和结果较多时通过分页查看。

1. 点击牌桌上的北、东、南、西，分别编辑四家条件：
   - **全牌**：点选全部 13 张，或粘贴 SHDC 点分牌谱，例如 `QJ6.K652.J85.T98`。
   - **条件牌**：默认拖动双端范围条指定大牌点、各花色长度；两端重合即固定值，端点不会互相越过。
     “更多”中仍可精确输入两个端点；四门必须能组成 13 张。
     仅调整点力会保留导入的精确牌型集合，实际修改花色张数才会替换为新的范围条件。
   - **不约束**：任意合法持牌。
   - **排除牌**：点选明确不会持有的牌；排除集合允许超过 13 张。
   - 其他模式也可勾选“同时排除指定牌”。每家条件取交集，四家共用一副 52 张牌。
   - 选牌按花色切换，每行七张；条件牌在“点力”和“花色张数”间切换。
     小菜单宽度不超过 282px，空间不足时内部滚动，标题和关闭按钮保持可见。
2. 定约步骤可跳过，默认分析北家 3S/3H/3D/3C/3NT。当前选择直接参与结算，无需额外添加。
   - 基础界面提供 1阶、2阶、成局牌、小满贯、大满贯；“更多”默认折叠，展开后有 3阶、4阶、5阶。
   - 成局牌填入 4S、4H、5D、5C、3NT。关闭 D、C 开关即可直接比较 4S、4H、3NT。
   - 花色开关始终可见；关闭花色同时移除已保留的该花色定约。
   - “高级设置”默认收起，可独立调整五种花色的阶数，关闭的花色保持关闭。
   - 每种花色的阶数数字与花色开关分开：点数字打开拨盘，点花色控制是否查询。
     手机在点力、张数的精确输入中点数字也可打开拨盘；上下拨动选择后点“确定”，取消或 Esc 不修改值。
     电脑长按数字约 0.3 秒，再向上或向下拖动可连续增减；精确输入仍支持键盘，Alt+↓ 可打开拨盘。
     范围条支持方向键逐个调整、PageUp/PageDown 每次五个、Home/End 移到允许的边界。
   - 如需多个庄家或同花色不同阶数，点击“追加对比”保留当前组，再修改阶数或切换庄家。
     结果列表显示全部实际参与结算的定约；“恢复默认五花色”清除追加组并恢复北家三阶。
3. 展开右上角“解析结果”，在其中选择“快速估计”或“全枚举真值”，需要时展开“计算参数”，再点击“开始结算”。收起结果时，这些设置一并隐藏。
   - 快速模式默认整次 20 秒、8 线程、目标 10,000 副、上限 100,000 副；参数可调。
   - 达到目标样本即发布结果，前端每隔 1 秒查询后端并展示最新结果；后台继续计算，直到样本上限或时间预算。
   - 复杂条件或大量定约可能达不到目标；任务停止时仍展示实际样本数及区间。
   - 全枚举不限时间/数量；达到目标样本后展示枚举前缀的总体概率上下界，每秒更新。
     只有完整空间穷尽后才标记真值；可随时取消。目标样本在两种模式下均可调整。
4. 页面轮询真实计算进度。刷新当前标签后可恢复同一服务中正在运行的任务并取消。
   解析期间可以修改条件，修改只作用于下次提交；旧结果会标记。
   - 简版达到目标后每秒更新最高胜率定约；达到目标前也更新后台状态和已解析副数。
     完整枚举才显示“精确值”；未穷尽的枚举按已解析牌局暂排名，并显示总体概率上下界，
     条件无解或没有样本时不会显示为 0%。
   - 简版与详情均保留“条件已改”的提示；计算完成、异常或取消后仍停留在牌桌。
5. 条件工具支持一键复制、导入粘贴 JSON、导入本地 JSON 文件、导出 JSON。
   文件格式是以 N/E/S/W 为键的后端条件对象；仅替换四家限制条件，不修改定约和计算参数。
   支持部分 `predeal`、`hcp`、`shape`/`shapes`/`shape_any` 和 `exclude` 的组合；导入前严格校验，
   失败时保留原条件，牌型集合不会被放宽为外包范围。部分已知牌和叠加排除牌通过编辑器标签切换。
6. 每家编辑器关闭按钮旁的“☰”菜单默认收起，提供“复制条件（JSON）”“导入条件”“保存条件”：
   - 单家复制输出不含方位键的条件 JSON，例如 `{"hcp":[15,17],"shape_any":[4,3,3,3]}`。
     导入也接受仅含一个方位键的对象；应用时仅替换当前一家，其余三家、定约和计算参数保留。
   - 点击“保存条件”，填写名称后“保存新模板”；选择模板可预览 JSON，再“应用到北家”等目标玩家。
     模板与方位无关，可用于任意一家。点力、精确牌型集合、已知牌、排除牌均会保留。
   - 修改模板名称或 JSON 后点“更新所选”；新建同名模板会提示冲突，不会覆盖原模板。
     删除模板需再次点击“确认删除”，删除不影响当前牌桌。
   - 模板保存在本仓库 `user_data/hand-templates.json`，跨浏览器、页面刷新和服务重启保留。
     此文件不提交 Git；备份或迁移时复制该文件。重置牌桌不会删除模板。
   - 单家复制、保存不受其他玩家尚未填完的条件影响；应用已知牌时检查与其他三家的重复持牌，失败保留原条件。
7. 可下载包含提交参数和后端完整结果的 JSON。页面不模拟实际叫牌或逐墩出牌。

所有概率均为 **DDS 双明手最佳攻防** 成约率。区间为同时覆盖选定定约、允许按时间停止的
95% confidence sequence。确定性枚举前缀仅给总体上下界，不作为随机估计；条件无解不显示为 0%。

## HTTP 接口

服务使用异步任务，单次只接受一个正在运行的解析，避免多个任务争抢资源而破坏预算。
保留最近 20 次任务；重启服务会清空。默认仅允许本机 Host 和同源浏览器请求；
通过 `--public-origin` 可额外允许一个固定的 HTTPS 公网来源，规则见上文。

`POST /api/jobs`，返回 HTTP 202 和 `{"id":"…"}`：

```json
{
  "conditions": {
    "N": {"predeal": "QJ6.K652.J85.T98"},
    "E": {"hcp": [10, 18], "exclude": "A..."}
  },
  "contracts": [
    {"declarer": "N", "level": 3, "strain": "NT"},
    {"declarer": "S", "level": 4, "strain": "S"}
  ],
  "exact": false,
  "budget_seconds": 20,
  "min_samples": 10000,
  "max_samples": 100000,
  "threads": 8
}
```

- 省略或传入空定约列表使用默认五花色；重复定约去重，最多 140 个。
- `GET /api/jobs/{id}`：`state`、已完成样本/耗时 `progress`、原请求和最新 `result`。
  达到 `min_samples` 时即发布 `result`，之后随完整批次完成更新；前端每隔 1 秒查询。`state: running` 和
  `result.status: running` / `result.running: true` 表示后台仍在计算。
  任务停止时无论是否达到目标均发布最终结果，`result.running: false`。
- `GET /api/jobs`：当前运行中的 `active_id`，用于新标签页恢复任务。
- `POST /api/jobs/{id}/cancel`：取消请求，父进程终止本次独立 DDS worker，并回收它。
- 错误输入 HTTP 400；正在计算时再次提交 HTTP 409；未知任务 HTTP 404。

Python API 同样支持 `query_success(conditions, contracts=[...])`，可加 `exact=True`。
`on_progress` 随计算批次接收检查点；首次达到目标后，每个新完成批次的检查点包含
同结构的 `result` 快照。计算批次不受前端轮询节奏约束；前端每隔 1 秒读取最新结果。
原生求解尚未完成新的完整批次时保留最近已完成的结果；所有定约使用相同的已完成牌局前缀。

本地模板接口使用相同的 Host / 同源检查：

- `GET /api/hand-templates`：返回 `{"templates":[{"id":"…","name":"…","condition":{…}}]}`。
- `POST /api/hand-templates`：传入 `{"name":"模板名称","condition":{"hcp":[15,17]}}`，创建模板，返回 HTTP 201。
- `POST /api/hand-templates/{id}`：传入相同字段，更新模板名称和条件，返回 HTTP 200。
- `POST /api/hand-templates/{id}/delete`：传入 `{}`，删除模板，返回 HTTP 200。
- 名称为 1–80 个字符；同名 HTTP 409，非法条件 HTTP 400，模板不存在 HTTP 404。
  文件损坏或写入失败返回 HTTP 500 并保留原文件；使用临时文件及原子替换保存。

多定约共用同一批条件均匀样本和总预算，每批完成全部定约后才计数。
同庄家同阶数复用牌局编码；严格证明的花色对称仍可减少求解数量，置信覆盖按实际不同求解数分配。
`exclude` 已覆盖条件校验、匹配、CP-SAT 枚举、快速拒绝采样、序列化/hash 和花色对称检查。
编译 v2 未实现排除牌直接计数，显式拒绝该条件；查询的快速模式使用完整 proposal 后过滤，
真值模式自动回退 CP-SAT，不会忽略排除条件。
