# 本地网页工作台

```bash
cd BridgeDealer  # 进入已克隆并安装好的仓库
./dealer serve
```

浏览器打开 <http://127.0.0.1:8789>。若端口被占用，可使用 `./dealer serve --port 8790`。
服务仅监听本机，页面、字体和脚本不依赖外部 CDN。静态 HTML/CSS/JavaScript 随 Python 包分发。
先按根目录 README 安装 Python 依赖并运行 `uv run python scripts/build_dds.py` 编译附带的 DDS 3.1.0；位置与命令行后端相同。

## 使用

页面固定在当前视口，不提供页面滚动。宽屏（大于 980px）右侧常驻玩家设置和定约设置；
窄屏点击牌桌上的四家打开玩家弹窗，点击中心盘打开定约弹窗。牌桌右下角开始结算，
右上角打开解析结果；定约和结果较多时通过分页查看。

1. 点击牌桌上的北、东、南、西，分别编辑四家条件：
   - **全牌**：点选全部 13 张，或粘贴 SHDC 点分牌谱，例如 `QJ6.K652.J85.T98`。
   - **条件牌**：填写大牌点上下界、各花色长度上下界。相同上下界即固定长度；四门必须能组成 13 张。
   - **不约束**：任意合法持牌。
   - **排除牌**：点选明确不会持有的牌；排除集合允许超过 13 张。
   - 其他模式也可勾选“同时排除指定牌”。每家条件取交集，四家共用一副 52 张牌。
2. 定约步骤可跳过，默认分析北家 3S/3H/3D/3C/3NT。当前选择直接参与结算，无需额外添加。
   - 基础界面提供 1阶、2阶、成局牌、小满贯、大满贯；“更多”默认折叠，展开后有 3阶、4阶、5阶。
   - 成局牌填入 4S、4H、5D、5C、3NT。关闭 D、C 开关即可直接比较 4S、4H、3NT。
   - 花色开关始终可见；关闭花色同时移除已保留的该花色定约。
   - “高级设置”默认收起，可独立调整五种花色的阶数，关闭的花色保持关闭。
   - 如需多个庄家或同花色不同阶数，点击“追加对比”保留当前组，再修改阶数或切换庄家。
     结果列表显示全部实际参与结算的定约；“恢复默认五花色”清除追加组并恢复北家三阶。
3. 选择快速估计或不限时真值，点击“开始结算”。
   - 快速模式默认整次 20 秒、8 线程、目标 10,000 副、上限 100,000 副；参数可调。
   - 复杂条件或大量定约可能达不到目标；如实展示实际样本数及区间。
   - 全枚举不限时间/数量，仅在完整空间穷尽后标记真值；可随时取消。
4. 页面轮询真实计算进度。刷新当前标签后可恢复同一服务中正在运行的任务并取消。
   解析期间可以修改条件，修改只作用于下次提交；旧结果会标记。
5. 条件工具支持一键复制、导入粘贴 JSON、导入本地 JSON 文件、导出 JSON。
   文件格式是以 N/E/S/W 为键的后端条件对象；仅替换四家限制条件，不修改定约和计算参数。
   支持部分 `predeal`、`hcp`、`shape`/`shapes`/`shape_any` 和 `exclude` 的组合；导入前严格校验，
   失败时保留原条件，牌型集合不会被放宽为外包范围。部分已知牌和叠加排除牌通过编辑器标签切换。
6. 可下载包含提交参数和后端完整结果的 JSON。页面不模拟实际叫牌或逐墩出牌。

所有概率均为 **DDS 双明手最佳攻防** 成约率。区间为同时覆盖选定定约、允许按时间停止的
95% confidence sequence。确定性枚举前缀仅给总体上下界，不作为随机估计；条件无解不显示为 0%。

## HTTP 接口

服务使用异步任务，单次只接受一个正在运行的解析，避免多个任务争抢资源而破坏预算。
保留最近 20 次任务；重启服务会清空。仅允许本机 Host 和同源浏览器请求。

`POST /api/jobs`，返回 HTTP 202 和 `{"id":"…"}`：

```json
{
  "conditions": {
    "N": {"predeal": "QJ6.K652.J85.T98"},
    "E": {"hcp": [10, 18], "exclude": "A..."}
  },
  "contracts": [
    {"declarer": "N", "level": 3, "strain": "NT"},
    {"declarer": "S", "level": 4, "strain": "S"}
  ],
  "exact": false,
  "budget_seconds": 20,
  "min_samples": 10000,
  "max_samples": 100000,
  "threads": 8
}
```

- 省略或传入空定约列表使用默认五花色；重复定约去重，最多 140 个。
- `GET /api/jobs/{id}`：`state`、已完成样本/耗时 `progress`、原请求和最终 `result`。
- `GET /api/jobs`：当前运行中的 `active_id`，用于新标签页恢复任务。
- `POST /api/jobs/{id}/cancel`：取消请求，父进程终止本次独立 DDS worker，并回收它。
- 错误输入 HTTP 400；正在计算时再次提交 HTTP 409；未知任务 HTTP 404。

Python API 同样支持 `query_success(conditions, contracts=[...])`，可加 `exact=True`。
多定约共用同一批条件均匀样本和总预算，每批完成全部定约后才计数。
同庄家同阶数复用牌局编码；严格证明的花色对称仍可减少求解数量，置信覆盖按实际不同求解数分配。
`exclude` 已覆盖条件校验、匹配、CP-SAT 枚举、快速拒绝采样、序列化/hash 和花色对称检查。
编译 v2 未实现排除牌直接计数，显式拒绝该条件；查询的快速模式使用完整 proposal 后过滤，
真值模式自动回退 CP-SAT，不会忽略排除条件。
